# ShellMenuKeeper

Windows 11 のエクスプローラで右クリックしたときのメニューを保守するツール。
アンインストールされたアプリや、バージョンアップで移動したアプリの登録が残り、
メニューに古い項目が出続ける問題を、**無効化**または**削除**で片付ける。

- リンク切れ（呼び先のファイルや DLL が無い）の項目を見つけて赤く表示する
- 項目ごとに「無効にする」（元に戻せる）か「削除する」（控えを作ってから）を選べる
- Windows 11 の新しいメニュー（「Paint で編集」など）の項目も無効にできる

## ⚠ 必ずお読みください：リスクと安全対策

**このツールは Windows のレジストリを書き換えます。** 誤った操作をすると、
右クリックメニューの項目が使えなくなったり、ファイルを開く・印刷するといった
アプリの動作に影響したりすることがあります。**使用は自己責任です**
（無保証。詳しくは [LICENSE](LICENSE)）。作者はいかなる損害にも責任を負いません。

### 安全のために、この順で進めてください

1. **まず「無効にする」を使う。** 無効化はいつでも「有効に戻す」で元に戻せる。
   削除は、無効にして問題が出ないことを確かめてからにする。
2. **重要な変更の前に、バックアップを取る。** このツールの自動の控えは、削除する
   その項目だけが対象。次のどちらか（できれば両方）を、使い始める前に作っておく。
   - **システムの復元ポイント**: スタートで「復元ポイントの作成」を検索 →
     「作成」を押す。
   - **レジストリ全体の書き出し**: 管理者のコマンドプロンプトで
     `reg export HKLM\SOFTWARE\Classes C:\backup\HKLM_Classes.reg` と
     `reg export HKCU\Software\Classes C:\backup\HKCU_Classes.reg`（`C:\backup` は先に作っておく）。
3. **削除すると、自動で控え（.reg）が作られる。** 控えが作れなかったときは削除しない。
   控えは `%LOCALAPPDATA%\ShellMenuKeeper\backups\` に保存され、画面の
   「控えから戻す...」で取り込める。操作の記録は同じ場所の `journal.log`。
   控えのフォルダは、消さずに残しておくこと。

### 知っておくべきこと

- **リンク切れの判定は完全ではありません。** 実在するのに「リンク切れ」と出る、
  逆にリンク切れなのに出ない、ということが起こりうる。判定できない項目は
  「リンク切れ」にしない作りだが、特殊な登録の見落としは避けられない。
  **削除する前に、その項目が本当に不要か、自分の目で確認する。**
- **「リンク切れ」でなくても、消してよいとは限りません。** Windows 標準の項目や、
  ProgID 配下の `open` / `edit` / `print` などは、ダブルクリックなどの**既定の操作**
  かもしれない。詳細欄に注意が出る項目は特に慎重に。
- **HKLM（全ユーザー共通）の項目は、PC を使う全員に影響します。** 変更には管理者権限が
  必要。「管理者として再起動」を使う。
- **拡張ハンドラの無効化は CLSID 単位**で効く。同じ CLSID を使う全ての場所のメニューから
  項目が消える。
- **Windows 11 の新メニュー（MSIX）の項目は削除できない**（パッケージの持ち物で、
  消しても更新で戻る）。無効にするだけが使える。完全に消すならアプリをアンインストールする。
- 「Explorer を再起動」は、開いているフォルダ窓を閉じる。作業中のファイルには影響しない。
- 配布の exe には**コードの署名がない**。Windows の SmartScreen が警告を出すことがある。
  信用できないときは、公開しているソースを読み、Python から実行してもよい。

## 動作環境

- Windows 11（Windows 10 でも動くと思われるが、動作確認は Windows 11 のみ）
- 開発と試験は Python 3.10。標準ライブラリだけで動く（追加のインストール不要）

## 起動

exe 版（Python 不要）: [Releases](../../releases) から `ShellMenuKeeper.exe` をダウンロードして実行する。

Python 版:

```
run.cmd
```

HKLM（全ユーザー共通）の項目を変更するには、画面の「管理者として再起動」を使う。
HKCU（自分だけ）の項目は管理者権限なしで変更できる。

## 画面の見方

- **リンク切れ**（赤）: 呼び先の実行ファイルや DLL が存在しない、または CLSID が未登録。
  古い登録の疑いが濃い。
- **無効**（灰）: 登録は残したままメニューから隠している。「有効に戻す」で復帰できる。
- 「リンク切れだけ表示」・「種類」・検索欄で絞り込める。見出しのクリックで並べ替えられる。

## 操作

| 操作 | 内容 |
| --- | --- |
| 無効にする | メニュー項目は `LegacyDisable`、拡張ハンドラは `Shell Extensions\Blocked`（HKCU）に登録。元に戻せる |
| 有効に戻す | 上の逆 |
| 削除する | 先に `.reg` の控えを作り、作れなければ削除しない |
| 控えから戻す | 控えを選んで取り込む。HKLM の控えは管理者権限が必要 |
| Explorer を再起動 | メニューの変更を反映する。開いているフォルダ窓は閉じる |

## 見ている範囲

HKCU と HKLM の両方で、次の場所の `shell`（メニュー項目）と `shellex\ContextMenuHandlers`（拡張ハンドラ）。

- `*` / `AllFileSystemObjects` / `Directory` / `Directory\Background` / `Folder` / `Drive`
- 拡張子ごと（`.xxx`）と `SystemFileAssociations\.xxx`
- 拡張子の既定値が指す ProgID（`txtfile` など）。詳細欄に対象の拡張子を出す
- **Windows 11 の新しいメニュー（MSIX）**: インストール済みパッケージのマニフェストにある項目
  （「Paint で編集」「Clipchamp で編集」「ターミナルで開く」など）

見ていないもの: `Applications\…\shell`（「プログラムから開く」まわり）。

### 新メニュー（MSIX）について

- 「無効にする」だけが使える。削除はできない。
- インストール済みでないパッケージの登録（旧版の残骸）は、メニューには出ないので一覧に出さない。

## exe 版を自分で作る

```
.\build_exe.cmd
```

`dist\ShellMenuKeeper.exe` ができる（PyInstaller が必要: `python -m pip install pyinstaller`）。
`cmd` では先頭の `.\` が要る。

## 開発

```
python -m pytest
```

試験は HKCU の専用の一時キーだけを使い、本物のメニュー登録には触れない。
